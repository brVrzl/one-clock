# Verified-observation hypothesis register

Audit date: 2026-08-21. Origin: AI-assisted post-audit brainstorming using only [`verified_fact_sheet.md`](verified_fact_sheet.md), followed by primary-literature collision checking. Every entry below is a **candidate explanation**, not a finding. No score is a truth claim.

## Frozen observations to explain

- O1: Task-0 global success is nonmonotonic over execution horizon.
- O2: Some fixed off-diagonal arm/gripper settings improve particular tasks/states, but the universal macro difference is uncertain.
- O3: A matched-query thresholded group-retention rule causes large success losses.
- O4: Thresholded prefix support is highly sensitive and destroys later recovery structure.
- O5: A sparse similarity-weighted ensemble of overlapping predictions reduces held-out teacher-forced action error relative to newest-only.
- O6: Sparse oracle group selection improves over scalar oracle selection, but the dimension-balanced margin is modest.
- O7: Action smoothness correlates with support but simple causal linear models explain little variance.
- O8: Gate-2B time-limit phase optima are broad/unstable and do not improve robustly over static controls.

## Adversarial synthesis

The most economical current explanation is a combination, not a single story: overlapping predictions offer some ensemble variance reduction (H02); similarity may guard against mode mixing (H03); independent group composition can create inconsistency (H09); and the existing support/phase proxies obscure these effects (H06/H08/H12–H14). This synthesis is **not verified**. It earns priority only because each component has a distinct small test.

The attractive “group-specific timescales” explanation is deliberately not privileged. It must beat the gripper-sign artifact, normalization sensitivity, finite-sample selection, smoothness, and cross-generation inconsistency explanations.

## Cheapest ordered discrimination sequence

1. Build a dense every-step prediction cache for a task/episode-stratified subset; do not train a router.
2. Recompute age curves, ACT exponential, uniform, similarity, fixed age, scalar oracle, independent group oracle, and consistency-constrained group oracle under control-aligned losses.
3. Run loss-weight, time-resampling, smoothness, disagreement, and event-label sensitivity.
4. Stop the group-specific hypothesis if its dimension-balanced oracle advantage is below a predeclared practical threshold or is not robust across tasks/losses.
5. Only then run a small paired, matched-query closed-loop comparison against ACT temporal ensemble and CogACT-style similarity weighting.
