## Question and confirmatory scope

Gate-4A2 tests external generalization of the frozen Gate-3C temporal-source
effect with a different independently trained public ACT checkpoint on all ten
vanilla LIBERO Spatial tasks. It is not a method search. All ten tasks and all
100 selected task-state blocks are primary; there is no development subset.

The primary outcome is binary task success. The design contains ten tasks,
ten common official initial-state IDs, and five methods, for exactly 500
official episodes. No task, state, method, or episode may be removed after an
outcome.

## Frozen methods

Let `E[t,q]` be the complete prediction for physical controller time `t`
generated by a query at observation/source time `q`. Each query yields a
100-step action chunk. Define the fresh prediction `F[t]=E[t,t]`. For `t>=20`,
define `O[t]=E[t,t-20]`, which is chunk offset 20 from source query `t-20`.

1. `A_NEWEST`: execute `F[t]` at every step.
2. `B_FULL_OLD20`: execute `F[t]` for `t<20`; execute `O[t]` for `t>=20`.
3. `C_ASYMMETRIC_FO20`: execute `F[t]` for `t<20`; for `t>=20`, execute
   `[F[t][0:6], O[t][6]]`.
4. `D_AGE_EXP_B003`: for every valid full-action prediction targeting time
   `t`, use one shared seven-dimensional scalar distribution
   `w_q proportional to exp(-0.03*(t-q))`, then execute the weighted complete
   action. Beta is fixed at 0.03.
5. `E_COGACT_A03`: reuse the exact Gate-3C shared full-action CogACT temporal
   weighting implementation with alpha fixed at 0.3.

The implementation imports the Gate-3C executor and scalar-weight code paths
directly. There is no checkpoint-specific retuning, action hold, gripper vote,
source-age sweep, additional partition, dynamic delay, learned routing, or
sixth method.

## State selection, seeds, and ordered schedule

Each of the ten tasks exposes the common official state-ID set `0..49`. Using
`numpy.random.default_rng(20260825)` and selecting ten IDs without replacement
produced the preserved unsorted RNG result
`[40,15,13,47,37,24,19,1,31,21]`. The frozen sorted set used for every task is
`[1,13,15,19,21,24,31,37,40,47]`.

For a block `(task_id,state_id)`, the episode seed is
`340000 + 100*task_id + state_id` and is shared across all five methods.
Blocks are traversed in ascending task ID and ascending selected state ID.
Within each block, method order is independently permuted using one continuing
`numpy.random.default_rng(20260826)` stream. The complete ordered 500-run
schedule is frozen in `audit_outputs/gate4a2_spatial_schedule.json`; its SHA256
is recorded in the preregistration manifest.

## Query fairness and execution rules

Every method receives the current observation and queries the frozen ACT once
per surviving controller step, producing and caching the same complete fresh
chunk through identical preprocessing and postprocessing. Methods differ only
in the temporal source of the executed action. Every episode must satisfy
`policy_queries == environment_steps`. No method may reuse an old chunk instead
of issuing the current query. There is no policy temporal ensemble, action
smoothing, or outcome-triggered rerun.

The runner may atomically write one log per completed scheduled cell for exact
resume. A log is resumable only when its task, state, method, seed, schedule,
configuration, checkpoint, processing assets, temporal source code, and
initial-state vector identities match. The execution continues until all 500
cells complete. Partial success summaries must not be printed or inspected.

## Four primary comparisons and frozen inference

The four and only four primary contrasts are:

- `C_ASYMMETRIC_FO20 - A_NEWEST`
- `C_ASYMMETRIC_FO20 - B_FULL_OLD20`
- `C_ASYMMETRIC_FO20 - D_AGE_EXP_B003`
- `C_ASYMMETRIC_FO20 - E_COGACT_A03`

For each comparison, report successes/total and rates, paired task-state mean
difference, first-only and second-only discordant blocks, the exact two-sided
paired McNemar/binomial diagnostic, 20,000 paired-block bootstrap draws,
20,000 task-cluster bootstrap draws over ten tasks, all per-task differences,
and every leave-one-task-out estimate. Percentile intervals use the 2.5th and
97.5th percentiles. There is no controller-step pseudoreplication and no
pooling with Gate-3C Object outcomes.

Paired-block bootstrap seeds are `20260911`, `20260912`, `20260913`, and
`20260914` for C-A, C-B, C-D, and C-E. Task-cluster seeds are `20261911`,
`20261912`, `20261913`, and `20261914`, respectively.

A contrast is **STABLE POSITIVE** exactly when the paired-block interval lower
bound is greater than zero, the task-cluster interval lower bound is greater
than zero, and every leave-one-task-out estimate is greater than zero. It is
**STABLE NEGATIVE** under the symmetric upper-bound and leave-one-task-out
conditions.

Decision precedence is frozen:

1. `SPATIAL-GENERALIZATION-CONTRADICTED` if C-A or C-B is stable negative.
2. `SPATIAL-GENERALIZATION-STRONG` if all four comparisons are stable positive.
3. `SPATIAL-GENERALIZATION-DIRECTIONAL` if C-A and C-B are stable positive but
   at least one of C-D or C-E is not stable positive.
4. `SPATIAL-GENERALIZATION-SUGGESTIVE` if all four point estimates are positive
   but the C-A and C-B stable-positive requirements are not both met.
5. `SPATIAL-GENERALIZATION-NULL` for all other complete outcomes absent a
   stable-negative directional comparison.

No effect-size threshold or additional hypothesis may be introduced after
outcomes.
