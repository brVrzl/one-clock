## Generational boundaries that must not be collapsed

- Static rollout success, demonstration-consistency support, fresh-query agreement, and Gate-2B phase-conditioned success are four different outcomes.
- Gate-2A “phase” is normalized demonstration duration; Gate-2B “phase” is `environment_step / 280`. They are not the same segmentation.
- Prediction horizon is fixed at 100 for ACT. Execution horizon is the number of actions committed. Temporal age is the difference between target time and source-observation time. Query interval is when ACT is called. These quantities coincide only in special baselines.
- Gate-1 uses 1,098 sparse source points; Gate-2A/reliability uses 3,740 sources; the new sparse temporal-expert audit uses overlapping predictions from that source sampling, not a dense every-step cache.
- The demonstration target and Y_refresh target disagree substantially and cannot share a single “reliability” conclusion.
