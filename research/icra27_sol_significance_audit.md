# SOL HIGH audit 2: scientific-significance reviewer

## Ranked shortlist

1. **Validity/recoverability-aware, coherence-constrained partial replanning (I06+I07+I08).** Potential phenomenon: action components lose validity at different physical times, while replacing still-valid commitments can hurt. The field would learn that age is not the control variable; counterfactual replacement value/recoverability is. Killer figure: time × subspace intervention surface predicting continue/partial/global refresh at equal query budget. Kill if recoverability cannot predict replacement value or partial refresh does not beat global refresh beyond LIBERO.
2. **Component-wise scheduling under fixed inference budget (I05).** Phenomenon: marginal value of a costly policy query differs by component and phase. Killer figure: success/recovery versus full-policy-call budget. Kill if a uniform/global schedule lies on the same frontier or gains vanish with faithful ACT aggregation.
3. **Causal source-age calibration plus failure-response taxonomy (I15+I10).** Strongest evidentiary spine, weaker standalone ceiling. Killer figure: arm-age × gripper-age response heatmap, phase/failure partitioned. Kill if interaction is seed/task specific or lacks a measured regime variable.
4. **Contact-triggered selective replanning (I03 within I02).** Strong focused hardware test but only a component of a stronger story. Kill if conventional force residuals explain gains.

## DCTA

**Use as ablation/diagnostic only.** It is a mechanism, not a phenomenon; current newest/CogACT/RoboTwin evidence does not support it as a general method. It would reverse the scientific order to optimize weights before identifying what makes an action valid.

## Recommendation

Center the program on **conditional recoverability and the value of temporal commitment**. Establish the causal intervention surface before building learned scheduling; selective replanning and DCTA are consequences/tests, not premises.
