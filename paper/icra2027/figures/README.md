# Active manuscript figures

All active artwork is generated by `../generate_figures.py`. Outputs are never
hand-edited. JSON interfaces in this directory are the tracked quantitative
source data. Python is the exclusive drawing, export, preview, and visual-QA
backend.

## Paper style

- FO20 and the selected developmental FO cell use one muted blue focal color.
- All full-action baselines use neutral grays.
- Fresh and old sources are distinguished by direct labels and fill/hatch, not
  by a red/green mapping.
- Text remains editable in SVG and is embedded as Type 42 in PDF.

## Figure contracts

### Figure 1

- Core conclusion: repeated queries provide same-time candidates whose source
  ages can be assigned independently by action component.
- Archetype: single-panel conceptual schematic.
- Output: ICRA double-column vector PDF/SVG, 178 mm wide.
- Evidence: definitions of `E_{t,q}`, `F_t`, `O_t`, and FO20.
- Reviewer risk: confusing source age with a gripper hold or lower query rate.

### Figure 2

- Core conclusion: the registered generic coherence contrast was unresolved,
  while FO supplied a post-hoc directional hypothesis.
- Archetype: annotated 2x2 matrix.
- Output: ICRA single-column vector PDF/SVG, 84 mm wide.
- Evidence: `gate3b_directional_figure_interface.json`, 100 paired blocks.
- Statistics: 20,000-draw paired-block and task-cluster 95% bootstrap CIs.
- Reviewer risk: mistaking the 62% FO cell for independent confirmation.

### Figure 3

- Core conclusion: the favored arm source reverses between teacher-forced error
  and closed-loop success, while the old gripper is favored in both views.
- Archetype: directional preference grid; no shared quantitative axis.
- Output: ICRA single-column vector PDF/SVG, 84 mm wide.
- Evidence: `offline_closed_loop_temporal_source_interface.json`.
- Reviewer risk: comparing heterogeneous raw metrics or implying causality.

### Figure 4

- Core conclusion: FO20 improves primary-cohort success over all four registered
  full-action comparators with positive paired and task-cluster interval lower
  bounds.
- Archetype: panel-first quantitative comparison and forest plot.
- Output: two true-size vector panels assembled by the manuscript.
- Evidence: `gate3c_figure4_interface.json`, 126 paired blocks.
- Statistics: 20,000-draw paired-block and task-cluster percentile bootstrap
  CIs; all leave-one-task-out estimates positive.
- Reviewer risk: hiding task clustering or implying uniform task-level gains.
