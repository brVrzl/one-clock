\section{Method and Experimental Setup}
\label{sec:setup}

\subsection{Same-target probe}
\label{sec:same-target}

At control step $t$, a Fresh component uses offset 0 from the chunk predicted
from the current observation. A component with source age $d$ instead uses
offset $d$ from the chunk queried $d$ steps earlier. Both entries were
originally predicted for the same physical step $t$. For example, A0G20 takes
the arm command from query $t$ at offset 0 and the gripper command from query
$t-20$ at offset 20. A20G0 swaps these assignments: the arm comes from query
$t-20$ at offset 20, and the gripper comes from query $t$ at offset 0. During
the first 20 steps, before the older source exists, every component executes
the Fresh offset-0 command.

Formally, let $q$ be policy-query time, $k$ the chunk offset, and $A_q[k]$
the predicted action entry. A valid same-target source satisfies
\begin{equation}
q + k = t .
\label{eq:same-target}
\end{equation}
The source age is $d=t-q$, so same-target alignment requires $k=d$. We
therefore measure the joint effect of an older source observation and a
longer-lookahead prediction; the probe does not separate those factors.
Same-target conditions make one whole-policy query at every environment step
and discard unselected predictions. They are diagnostics, not deployment
executors.

\subsection{Policy, clock, and action components}

We evaluate fixed ACT policies~\cite{zhao2023act} using the installed LeRobot
v0.4.4 implementation~\cite{cadene2026lerobot} in LIBERO simulation
~\cite{liu2023libero}. The evaluator runs at 20~Hz, so one chunk index is
0.05~s and $d=20$ is 1.00~s. ACT predicts 100-step chunks without action
smoothing. Unless temporal ensembling is explicitly named, it is disabled.
The seven-dimensional relative end-effector action comprises translation
(dimensions 0--2), rotation (3--5), and gripper (6).

\subsection{Cohorts, schedules, and inference}

A paired block is one task--initial-state pair evaluated under each compared
condition with matched seeds, preprocessing, step caps, and success criteria.
The primary preregistered cohort contains 140 blocks across five LIBERO-Goal
and five LIBERO-10 tasks. The Object development cohort contains 126 blocks
across nine tasks. Track A contains 450 blocks across LIBERO-10, Goal, and
Spatial. Periodic H$h$ execution queries every $h$ steps and commits both
components to that chunk. ARM$h$\_GRIP$g$ uses separate arm and gripper
commitment horizons. Dense-query controls query every step but execute the
scheduled source and discard unused predictions.

Success is binary. Paired contrasts use two-sided exact McNemar tests. We
report paired risk-difference intervals and task-cluster bootstrap intervals
already fixed in the canonical analysis. No new inference is introduced here.
