\section{Related Work}
\label{sec:related-work}

\subsection{Action chunking and temporal ensembling}

ACT predicts action chunks and can aggregate overlapping predictions through
temporal ensembling~\cite{zhao2023act}. Recent analysis studies why chunking can
improve behavioral cloning and how policy context changes the value of
open-loop execution~\cite{lazzati2026actionchunking,zeng2026openloop}. We hold
the trained chunk policy fixed and ask a different question: whether the same
temporal source assignment has different behavioral consequences across action
components.

\subsection{Whole-policy execution adaptation}

Replanning methods select how much of a chunk to execute before the next policy
query. Their signals include attention, predicted motion phase, learned
continue-or-replan decisions, visual deviation, and verified prefixes
~\cite{wang2026autohorizon,nie2026pace,zhao2026dehp,xu2026bcp,
pan2026vlacorrector,chen2026a3}. RTC instead handles asynchronous inference by
preserving actions that must execute and inpainting the remainder of a new
chunk~\cite{black2025rtc}. These methods primarily apply a temporal decision to
the whole action. Our executable comparisons hold the arm cadence fixed while
changing gripper commitment.

\subsection{Stale predictions and asynchronous execution}

Staleness arises whenever inference and control run on different clocks or an
executor reuses a stored prediction. RTC directly addresses asynchronous
chunk generation~\cite{black2025rtc}; adaptive-horizon methods address when to
replan~\cite{wang2026autohorizon,nie2026pace}. Same-target alignment instead
changes the source age of selected components while preserving their intended
physical target. This diagnostic isolates neither latency nor compute and
couples observation age with prediction lookahead.

\subsection{Heterogeneous action generation}

Robot actions can also be structured at the representation and generation
levels. ARP permits different chunk sizes for different action types
~\cite{zhang2025arp}. Our policy still predicts one seven-dimensional chunk;
component identity enters only when the executor selects which same-target
source supplies translation, rotation, or gripper commands.
