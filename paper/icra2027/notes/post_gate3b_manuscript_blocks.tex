\subsection{Cross-generation action composition}

Let $E_{u,q}$ denote the action for physical controller time $u$ predicted by
the frozen policy query at source time $q$.  At time $t$, the current query
provides the fresh prediction
\begin{equation}
F_t = E_{t,t},
\end{equation}
and the query issued $d=20$ controller ticks earlier provides
\begin{equation}
O_t = E_{t,t-20}.
\end{equation}
The source gap is one second at the audited 20-Hz controller.  We write
$F_t^{a}$ and $O_t^{a}$ for the six-dimensional arm components, and
$F_t^{g}$ and $O_t^{g}$ for the gripper component.  For $t\geq20$, the four
deterministic conditions execute
\begin{align}
\mathrm{FF}_t &= [F_t^{a},F_t^{g}], &
\mathrm{OO}_t &= [O_t^{a},O_t^{g}],\\
\mathrm{FO}_t &= [F_t^{a},O_t^{g}], &
\mathrm{OF}_t &= [O_t^{a},F_t^{g}].
\end{align}
FF and OO preserve one source generation for the complete action.  FO and OF
recompose arm and gripper components across the two generations.  Before the
old source exists, every condition executes the same fresh action.

Each paired task--state block $i$ supplies binary success outcomes
$S_{i,c}\in\{0,1\}$ for conditions $c\in\{\mathrm{FF},\mathrm{OO},
\mathrm{FO},\mathrm{OF}\}$.  The primary closed-loop estimand is
\begin{equation}
C_{\mathrm{coherence}}=
\frac{1}{N}\sum_{i=1}^{N}
\left[
\frac{S_{i,\mathrm{FF}}+S_{i,\mathrm{OO}}}{2}
-\frac{S_{i,\mathrm{FO}}+S_{i,\mathrm{OF}}}{2}
\right].
\end{equation}
Positive values favor source-coherent actions at the same marginal assignment
of fresh and old arm and gripper sources.  This contrast changes sign if mixed
actions perform better and is zero when the symmetric interaction is absent.

\subsection{Why a separable offline loss cannot measure the interaction}

Consider any teacher-forced loss that separates by action group,
\begin{equation}
L(a^{a},a^{g})=L_a(a^{a})+L_g(a^{g}),
\end{equation}
where both terms compare their argument with the same target action.  Define
$A_F=L_a(F_t^{a})$, $A_O=L_a(O_t^{a})$, $G_F=L_g(F_t^{g})$, and
$G_O=L_g(O_t^{g})$.  Then
\begin{align}
L(\mathrm{FF}) &= A_F+G_F, &
L(\mathrm{OO}) &= A_O+G_O,\\
L(\mathrm{FO}) &= A_F+G_O, &
L(\mathrm{OF}) &= A_O+G_F.
\end{align}
Therefore,
\begin{align}
&L(\mathrm{FF})+L(\mathrm{OO})-L(\mathrm{FO})-L(\mathrm{OF})\\
&=(A_F+G_F)+(A_O+G_O)-(A_F+G_O)-(A_O+G_F)=0.
\end{align}
The identity holds for every target before any averaging or bootstrap.  It also
holds for the frozen Gate-3A1 semantic loss because its translation and rotation
terms belong to the arm addend and its gripper-sign term belongs to the gripper
addend: $L_a=(3L_{trans}+3L_{rot})/7$ and $L_g=L_{grip}/7$.  The identity does
not show that mixed actions are harmful, beneficial, or behaviorally equivalent.
It shows only that an additive offline loss has no arm--gripper interaction term
with which to detect this symmetric composition effect.
